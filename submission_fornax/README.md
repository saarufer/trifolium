# Task2 提交方法 — Fornax：规则开局 → LLM 精修 + 间隔强反思

一个**感知→决策→行动→反思**的自治分子设计 agent。给定靶点 PDB，自动识别口袋、
用 AutoDock Vina 真实对接驱动，设计一个**深结合 + 可合成 + 路线可行**的分子。

核心创新：**规则与 LLM 分工**——规则负责确定性的高频深耕（不崩盘），
LLM（Claude）负责规则永远做不到的**战略级骨架/连接子重设计**。

---

## 架构（一句话）

> **规则先打底铺路（保证不崩），LLM 在好种群上做战略精修，并每隔几次"强制深度反思"破停滞。**

```
口袋识别(离线) → 规则开局(前~15轮纯规则,稳爬到 -11~-12)
              → LLM 精修(过采样设计 + 间隔强反思)
              → 四道防假阳门把关 → 可合成的深结合冠军
```

## 为什么这样设计（每个决策都有实验依据）

我们跑了十余次对照实验（代号见 `../experiments_log/`），逐步逼出这个架构：

| 设计 | 解决的问题 | 实验证据 |
|---|---|---|
| **规则开局**（前 N 轮纯规则，之后才开 LLM） | **LLM 开局方差极大、~50% 崩盘** | 「LLM 开局」两局崩到 −9.76 / −9.38；改规则开局后三局保底稳定 −11.5，**崩盘根治** |
| **LLM 战略精修** | 规则只会加取代基/融环，**做不到换连接子/换骨架** | LLM 把单酰胺 C(=O)N → 二酰亚胺 urea，推动 −13→−16；规则永远做不到 |
| **间隔强反思**（每 3 次 LLM 调用 1 次低温深度反思） | LLM 后期**复读同一句、空转烧 API** | 反思轮 temp 0.1 强制「为什么卡住→攻那个具体缺口」，复读时提前触发，破停滞 |
| **温度反差**（探索 0.4 / 反思 0.1） | 减方差和保多样性**矛盾** | 探索轮发散保上限，反思轮收敛破局，分工不互相牺牲 |
| **四道防假阳门** | Vina 有四类系统性假阳性 | 见下表，逐一设防 |
| **过采样择优**（第一次设计 18 个，dock 后留最深） | 单次 LLM 采样运气差 → 整局废 | 起点从单批 −7.8 提到 18 选 −11.1 |
| **并行对接** | 服务器吞吐 | ThreadPool 并行 dock，~核数倍加速 |

### Vina 的四类假阳性 & 对应的门

| 假阳类型 | 特征 | 防住它的门 |
|---|---|---|
| 柔性假阳 | 可旋转键多，结合熵未付 | rigidity 门（rot ≤ 6）|
| greasy 假阳 | 长脂肪链无环 | `_greasy` |
| PAH 平面假阳 | coronene 类纯碳稠环，刷深分但不可合成 | routable 门（route 优先选择）|
| 难嵌入假阳 | 太复杂，3D 构象生成不稳定 → 扭曲构象的假深分 | **embed 稳定性门** |

> 教训：**每解锁一个让 agent 探得更深的旋钮，就会暴露一类新的 Vina 假阳性**——优化与设防必须同步。

## 实测战力（TYK2，真 Vina，两局复跑验证）

| 局 | 最深 Vina | embed 可信 | 可合成 |
|---|---|---|---|
| Fornax | **−15.66** | 3/3 ✅ | ✅ |
| Fornax2（复跑） | **−15.05** | 3/3 ✅ | ✅ |

两局都稳定落在 −15 区间、全程 embed 可信、可合成——**「规则开局→LLM精修+强反思」是稳定架构，不是单局运气。**

## 工程要点（提交相关）

- **LLM 联网**：Claude 经新加坡 ECS 代理（`ANTHROPIC_BASE_URL=http://43.98.197.239`）调用；
  key 经 build-arg 注入。**ECS 不可达时优雅降级到纯规则**（规则保底，绝不崩）。
- **三归零雷防护**：route 列永远含合法 `>>`、产物匹配分子、非退化；坏 route 在 `write_csv` 被自动纠正。
- **时间预算**：每靶 ~73 分钟（3 靶 ≈ 3h39m），三层 watchdog + 外层硬超时，保证按时交付。
- **依赖**：rdkit + numpy + anthropic 0.109.1 + httpx 0.28.1（版本经镜像内联通验证）。
